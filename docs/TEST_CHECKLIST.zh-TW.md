# VoxSum 功能測試清單（v0.12.7）

在自己的手機上逐項測試，勾選 ✅／❌，遇到問題請寫下**手機型號、Android 版本、發生了什麼**（最好附截圖）。

**安裝：** 從 [Releases](https://github.com/vieenrose/VoxSumDroid/releases/latest) 下載最新 APK 安裝。首次使用會下載模型（需要網路一次），之後可完全離線。

## A. 匯入音訊（五種來源）

- [ ] **音訊檔案**：加入音訊 → 音訊檔案，挑一個 mp3/m4a/影片檔 → 開始轉錄
- [ ] **即時錄音**：加入音訊 → 錄製，說幾句話 → 句子邊說邊出現 → 按停止後自動產生摘要
- [ ] **Podcast**：搜尋一個節目 → 挑一集 → 下載並轉錄
- [ ] **YouTube**：貼一條影片網址（也試試關鍵字搜尋）→ 擷取音訊並轉錄
- [ ] **從其他 App 分享**：在 LINE／檔案管理器選一個語音檔 → 分享 → VoxSum 出現在分享選單並開始轉錄
- [ ] **首次模型下載**：有進度條；下載完成後功能正常

## B. 轉錄與摘要

- [ ] 逐字稿**即時**逐句出現，轉錄中就能捲動閱讀
- [ ] 每句依**語者**標色，顯示語者數量（用兩人以上的對話音檔測）
- [ ] 轉錄完成後自動產生**標題**與**摘要**
- [ ] ↻ 選單 →「偵測名稱」：能從對話內容推測語者姓名
- [ ] ↻ 選單 →「擷取行動項目」：產生待辦清單（用會議類音檔測）
- [ ] 🔍 **搜尋**逐字稿：符合處高亮，上下箭頭可切換

## C. 播放器

- [ ] 點任一句 → 跳到該時間點播放
- [ ] 播放時當前句子自動高亮並捲動
- [ ] **轉錄還在進行時**按播放：正常；且**轉錄結束的瞬間**播放位置不會跳回 0:00

## D. 編輯

- [ ] 直接修改一句逐字稿文字 → 保存後 App 提示摘要已過期、可重新摘要
- [ ] 重新命名語者；把一句改指給另一位語者；合併兩位語者
- [ ] 修改標題 → 之後重新摘要時**不會**蓋掉你自己寫的標題

## E. 摘要設定與重跑

- [ ] 設定 → 換**摘要語言**（如改成 English）→ 回到主畫面有提示 → 一鍵重新摘要，摘要與標題都變成新語言
- [ ] 摘要語言只在 **繁體中文 ↔ 简体中文** 之間切換 → 標題、摘要、逐字稿**立即**轉換（不用等 AI 重跑）
- [ ] 換**摘要風格**（條列／重點／敘述）→ 重新摘要後風格改變
- [ ] ↻ 選單重新轉錄：舊逐字稿被新結果取代，不會混在一起

## F. 儲存、分享、匯出

- [ ] **儲存工作階段（.m4a）** → 回首頁 → 從「最近」或「開啟工作階段」重新打開：標題、摘要、語者、封面全部還在
- [ ] 匯出的 .m4a 丟到音樂播放器（如 Retro Music）能播，並顯示標題／封面／歌詞
- [ ] 匯出 `.txt`、`.srt`、`.md`、`.pdf` 各一次，檔案內容正確
- [ ] **轉錄進行中**：匯出選單與設定應該是**鎖住**的；轉錄完成後解鎖

## G. 外觀與其他

- [ ] 設定 → 外觀：**自動／淺色／深色／電子紙** 四種都切換一次，介面正常、文字可讀
- [ ] 自動模式：切換手機系統深色模式，App 跟著變
- [ ] 設定 → 儲存空間：看得到各模型大小；刪除一個模型 → 下次使用時自動重新下載
- [ ] （可選）把某個模型刪到一半／斷網製造下載失敗 → App 顯示錯誤與**重試**按鈕，按重試能復原
- [ ] 開飛航模式，重複 B、C、D：全部功能離線可用
