這是一趟 5 分鐘的導覽，涵蓋桌面版的所有功能。全程不需要帳號；模型只在第一次使用時下載一次，之後不會有任何資料離開你的電腦。

## 安裝與啟動

```bash
sudo dpkg -i voxsum_<版本>_amd64.deb    # 取自 desktop-v* 的 GitHub Release
```

程式會安裝到 `/opt/voxsum`，並在應用程式選單（AudioVideo 類別）加入 **VoxSum** 項目。播放與音訊解碼需要系統的 **`ffmpeg`**（`PATH` 內）— 若尚未安裝，請用發行版安裝（`sudo apt install ffmpeg`）。從選單啟動，或執行 `/opt/voxsum/bin/VoxSum`。

> **第一次執行會下載模型。** 第一次轉錄時會下載語音與語者模型，第一次摘要時會下載摘要模型（來自 Hugging Face，會做完整性檢查，存到 `~/.local/share/VoxSum`）。下載時會顯示進度條，之後即可完全離線。若下載中斷，VoxSum 會清掉並讓你重試。

## 1. 匯入音訊

點 **➕ 新增音訊**（空白畫面上的主要按鈕，或頂列的 **開啟 / Open**），選擇來源：

| 來源 | 用途 |
|---|---|
| **音訊檔** | 電腦上任何音訊／視訊 — 用系統原生檔案對話框選取。 |
| **錄音** | 即時錄下會議，邊講邊看逐字稿出現。 |
| **線上 → Podcast** | 搜尋節目、選一集、直接轉錄。 |
| **線上 → YouTube** | 貼上連結或用關鍵字搜尋。 |
| **開啟工作階段（.m4a／.ogg）** | 重新開啟先前儲存的工作階段，繼續編輯。 |

**錄製會議** —「錄音」會從系統預設的輸入裝置擷取；邊講字句邊出現，狀態列的**音量指示條**顯示麥克風確實收到聲音，按 **停止** 後便完成摘要。過小的音源（遠距離會議室麥克風）會自動增益 — 轉錄與播放皆受惠。

## 2. 閱讀與理解

- **誰在何時說話** — 每一行都依語者標註並以顏色區分，播放列會顯示各語者的色帶時間軸。語者數量會**自動偵測** — 神經網路分段器先描出語者邊界，數量由聲音相似度結構決定；你不需要設定任何門檻。較長的處理會顯示**預估剩餘時間**（「辨識語者中… 約剩 3 分鐘」），摘要階段也一樣。VoxSum 還能**從內容推測語者的真實姓名**（頂列 **↻ 重新執行 → 偵測姓名**）。
- **同步播放器** — 像音樂 App 一樣停在底部：點任一行即可跳到該處；播放時當前行會高亮，逐字稿也會**自動捲動**以保持該行在畫面內。
- **搜尋** — 頂列的 🔍 可在長錄音中找出任何字詞；符合處會高亮，可逐一切換。
- **舒適的字級** — **A− / A+** 按鈕會縮放逐字稿、標題與摘要（工具列與播放器維持不變）。高解析度螢幕會自動偵測；若偵測有誤，可用 `VOXSUM_UI_SCALE=1.5` 覆寫。
- **你想要的摘要** — 一個簡短標題，加上精簡的摘要（至多數個要點，以 **Markdown** 正確排版，過長時折疊為「顯示更多」），風格可選**條列、主管摘要或敘事**（在設定裡選），並可用你選的語言呈現。摘要語言與音訊語言無關 — 例如可為中文逐字稿產生英文摘要。
- **行動項目** — 頂列 **↻ 重新執行 → 擷取行動項目**，會從會議中拉出「誰該做什麼」與重要決議的草稿清單。

## 3. 依你所需調整

- **編輯任何內容** — 就地修正字詞、重新命名語者，或微調標題／摘要。
- **修正語者** — 在任一行，⇄ 選單可把標錯的行移到正確的人，或把兩個語者合併為一。
- **重新執行** — 頂列的 **↻** 選單可重跑轉錄、摘要、**單獨的語者辨識**（*重新辨識語者* — 不必整段重新轉錄）、姓名偵測或行動項目擷取，並會追蹤彼此的相依關係：改了摘要語言或風格、或編輯了逐字稿，它會提供一鍵重新摘要。若只是在 **繁體中文 ↔ 简体中文** 之間切換，標題、摘要與逐字稿會**即時**轉換 — 無需重跑。

## 4. 儲存、分享、匯出

開啟頂列的 **匯出** 選單。轉錄仍在進行時，匯出與設定會暫時鎖定，以免存到只做一半的工作階段 — 完成後自動解鎖。

- **儲存工作階段（.m4a 或 .ogg）** — 把整個工作階段（音訊 ＋ 逐字稿 ＋ 摘要 ＋ 語者 ＋ 封面）打包成單一檔案，能在**任何媒體播放器**播放（顯示標題、封面，並把逐字稿當作同步歌詞），也能在 VoxSum 中**重新開啟**且完整還原。`.m4a` 是預設格式，與 Android 版一致，因此工作階段可在桌面與手機之間互通。這就是你的封存 — 隨時可透過 *新增音訊 → 開啟工作階段* 重新開啟。
- **匯出逐字稿** — 純文字（`.txt`）、字幕（`.srt`、`.vtt`）、Markdown（`.md`），或可列印的 **PDF**（系統裝有 Noto Sans CJK 字型時支援中日韓文）。

重新開啟與儲存過的工作階段會出現在側欄的 **最近** 清單，點一下即可繼續。

## 5. 值得一看的設定

- **外觀** — **淺色**、**深色** 或 **電子紙**（扁平高對比主題）。**自動**（預設）會跟隨系統的淺／深色設定。
- **摘要語言** — 沿用逐字稿語言，或選 English · Français · 繁體中文 · 简体中文 · 日本語 · 한국어。
- **摘要風格** — 條列／主管／敘事。
- **轉錄引擎** — 預設中文＋英文；多語引擎（中文 · 英文 · 日文 · 韓文 · 粵語）一鍵即可切換。
- **語者** — 開／關語者分離，或提示固定的語者數（否則數量自動判定）。
- **模型** — 查看每個已下載模型佔用的磁碟空間，並可刪除以釋放空間（下次使用時會重新下載）。
